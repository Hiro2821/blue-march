# ブルーマーチ

青い軍隊を育てて、赤い敵軍とボスを倒す 3D風ブラウザゲーム。
HTML / CSS / JavaScript のみ（ビルド・サーバー不要）。

## 遊び方
- 画面を左右にスワイプ（PCはマウスドラッグ、または ←→ / A D キー）
- 青いゲートをくぐると兵士が増える（+N / ×N）
- 敵軍を全滅させてゴールの城門へ。3の倍数ステージはボス戦
- クリア報酬のコインで「初期兵士」を強化できる

## 公開（GitHub Pages）
このフォルダ（index.html / style.css / game.js）をリポジトリに置いて Pages を有効にするだけ。
セーブは localStorage（キー: blueMarch.save.v1）。
