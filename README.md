# ブルーマーチ

青い軍隊を育てて、赤い敵軍とボスを倒す 3D風ブラウザゲーム。
HTML / CSS / JavaScript のみ（ビルド・サーバー・外部API不要）。iPhone / iPad の Safari、PC ブラウザで動作します。

## 遊び方
- 画面を左右にスワイプ（PCはマウスドラッグ、または ←→ / A D キー）
- 左右のパネル（ゲート）から選んで通過。パネルは3系統
  - **増減**：`+10 +20 +30 +50 +100…` `×2 ×3`（良）／ `−10 −20 −30 ÷2 ×0.5`（悪）
  - **特殊**（紫）：攻撃力・体力・攻撃速度・コイン獲得量アップ（そのステージ中）／ 無敵（6秒）／ 兵種の追加・変更
  - **リスク付き**：`+100 ⚠敵+40%` のように、大きな報酬と引き換えに次の敵部隊が増える罠。`敵+30%` だけのパネルもある
  - 連続して現れるパネルや、どちらを選んでも痛い二択もあり、ステージが進むほど複雑になる
  - 兵士数は最小1・最大999,999に制限
- 敵軍は自動で戦闘。ステージ最後に必ずボスが待つ
- ボスを倒すとゴールはすぐ目の前（約1秒でクリア）
- ステージ途中で出る「強化3択」で、そのステージ限りの強化を選ぶ
- 分岐ルート：兵士増加 / コイン獲得 / 強敵撃破 から選ぶ

## 兵種
| 兵種 | 特徴 |
|---|---|
| 剣士 | 標準。近接 |
| 弓兵 | 遠距離から攻撃。体力は低め |
| 重装兵 | 高耐久・低攻撃。前列で壁になる |
| 魔法兵 | 範囲攻撃。敵が多いほど有利、ボスには弱い |

兵種はコインで解放し、「兵士」タブで出撃編成を調整できます。

## メタ進行（タブ画面）
- 🏠 ホーム：続きから出撃、放置報酬の確認
- 🗺️ ステージ：到達済みステージを選んで再挑戦
- 🛡️ 兵士：兵種の解放・編成
- 🔨 強化：初期兵士数 / 攻撃力 / 体力 / 攻撃速度 / コイン獲得量（レベルごとに費用上昇）
- 📋 ミッション：達成でコイン報酬
- 🏅 実績：解除状況・自己記録
- 放置報酬：最大8時間分。次回起動時に受け取り

## 公開（GitHub Pages）
リポジトリの Settings → Pages → Source を `main` / `(root)` にすると公開されます。
`https://<ユーザー名>.github.io/blue-march/`

## セーブ
localStorage（キー: `blueMarch.save.v2`）。旧 v1 セーブ（コイン・ステージ・初期兵士強化）は自動で引き継がれます。

## ファイル構成
- `index.html` / `style.css`
- `js/data.js` 定数・兵種 / `save.js` セーブ / `art.js` 兵士スプライト / `boss.js` ボス
- `js/stage.js` ステージ生成 / `game.js` エンジン・描画 / `meta.js` 強化・ミッション・実績・放置 / `ui.js` 画面
